## 코드와 검증 범위

- 로그인 안내의 정확한 `로그인하기` 버튼만 한 번 누른다. 기존 세션이 상품 화면으로 돌아온 경우 원래 요청 링크를 다시 연 후 상품 식별을 다시 수행한다.
- 비밀번호·인증·동의 화면에서는 진행하지 않는다. 인증 화면 XML은 메모리로만 읽는다. 저장된 자격증명을 배치에 추가하지 않았다.
- 배치 결과의 실패/보류 항목에 상품명과 판매처를 포함하도록 보완했다.
- 관련 ADB 테스트 33개 통과. USB 연결, Windows 운영 계정 로그인, 앱 세션이 필요한 운영 조건은 그대로다.
- 상품별 별칭 승인, 일반가/조건부 할인 분리, 오연결 수정, 신규 가격행 생성은 이번 실행에서 변경하지 않았다.
