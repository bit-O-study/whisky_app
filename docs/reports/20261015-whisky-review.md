### 구현 구조와 재개 위치

1. 기존 상품: `refresh-links.mjs`로 저장된 URL을 해석해 앱 상세를 열고 가격을 수집한다. `apply-link-prices.mjs`로 실제 DB 연결을 확인한 후 갱신한다. 이름의 단순 표기 차이는 차단 사유로 삼지 않는다.
2. 신규 상품: `collect.mjs --links`로 목록·상품명·용량·가격·할인조건 및 공유 미리보기의 실제 URL을 수집한다. `register-products.mjs`는 상품과 링크를 등록하고 가격은 별도로 검증한다.
3. 현재 중단된 체크포인트: `artifacts/adb/full-links-20261015/checkpoint.json`. 화면 상태를 복구한 뒤 같은 출력 경로와 `--resume`으로 재실행한다. 기존 링크는 재사용하지만 목록 위치는 처음부터 다시 순회한다.
4. 원본 화면·DB 백업·변경 영수증은 Git 제외 `artifacts/adb/`에 보존한다. 상세 명령과 제한은 [수집기 설명](../../scripts/adb/README.md)에 있다.

다음 작업: 화면 인식 중단 원인 해결 → 이마트·트레이더스 목록 끝까지 수집 → 신규 상품 중복 대조·등록 및 가격/메타데이터 보강 → 남은 기존 링크 예외 처리 → DB 및 운영 화면 최종 대조.
