# Catalog Browse And Search

## 사용자 문제
- 사용자는 주류를 빠르게 검색하고, 판매처별 가격을 비교하며, 긴 목록에서도 탐색 흐름을 잃지 않아야 한다.

## 현재 제품 계약
- 첫 페이지는 가능한 한 서버 선조회로 빠르게 보여준다.
- 검색은 부분 일치 기반으로 동작한다.
- 목록은 무한 스크롤로 이어진다.
- 카드에서는 판매처별 가격 비교를 바로 확인할 수 있어야 한다.
- 카드와 오버레이의 판매처 항목은 외부 구매 페이지로 열려야 한다.
- 추천 기능은 현재 범위에 포함하지 않는다.

## 상호작용 기준
- 헤더의 브랜드 영역은 상단 복귀 진입점이다.
- 데스크톱/모바일 모두 상품 행의 명시적인 가격 비교 펼침 제어를 사용한다. 상품명은 상세 화면으로 연결한다.
- 종류/용량/판매처 필터와 정렬은 현재 불러온 상품에 적용되며 화면에 범위를 설명한다. 판매처 필터는 상품의 판매처 존재 여부를 검사하고, 해당 상품의 전체 판매처 비교는 유지한다.
- 수집된 시각을 한국 시간으로 표시하고 미제공이면 명시한다. 가격/도수만으로 희귀 상품이나 캐스크 스트렝스를 추측하지 않는다.
- 검색, 목록 조회, 추가 페이지 로딩은 서로 충돌하지 않아야 한다.

## 프로모션 배너
- 헤더 아래에 간결한 함께하는 서비스 링크 행을 표시한다.
- IQ 검사, 헬쑤, 프로젝트 메모를 표시하며 세 서비스 모두 웹으로 연결한다. 프로젝트 메모는 https://meeting-minutes-orcin.vercel.app 이며 APK 다운로드 링크가 아니다.
- 자동 전환 없이 모든 링크를 바로 선택할 수 있다.

## 화면 품질 기준
- UI 리뉴얼이나 polish는 기능 회귀 없이 이 계약 위에서 이뤄져야 한다.
- 카탈로그는 브랜드 톤을 가지되, 가격 비교 가독성을 해치면 안 된다.
- 서버 페이지 대기는 브랜드 로고와 로딩 안내를, 검색/목록 조회는 상품 행 형태의 스켈레톤을 표시한다. 추가 조회 시 기존 상품은 유지한다.
- 빠른 요청의 깜빡임을 줄이기 위해 웹 로딩 표현은 180ms 후 나타나며 실제 데이터 응답을 지연하지 않는다. 동작 줄이기 설정을 존중하고 스크린리더에 상태를 알린다.
- Android는 상단 가로 진행바 없이 화면 중앙의 원형 버퍼링 표시를 사용한다. 첫 진입과 문서 이동이 180ms 이상 걸리면 표시하고 화면 준비/실패 시 해제한다. 연결 오류 시 재시도를 제공한다.
