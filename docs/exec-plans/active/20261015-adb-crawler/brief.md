# ADB 앱 가격 수집 계획

## 2026-10-27 예약 실행 검증 요청

후속 승인: 보류된 26개 링크를 실제 앱에서 재확인하고 상품 별칭, 잘못된 링크, 누락 가격행, 일반 판매가/할인 구분, 큰 가격 변동을 고친다. 매장 품절은 실제 상태로 유지하며 구매 가능으로 바꾸지 않는다. 검증한 값만 운영 DB에 반영하고 배치를 다시 검증한다.
사용자가 기존 배치 예약 시간을 가까운 시각으로 바꿔 실제 스케줄러 실행과 가격 반영을 검증하고, 미반영 상품별 사유를 설명하도록 요청했다. 기존 작업·코드를 백업하고 최신 수집기를 설치 경로에 반영한다. 일회성 검증 트리거 종료 후 매일 한국 시각 04시 예약만 유지한다. 로그인/USB 상태와 상품 검증 보류를 구분해 보고한다.

초기 사용자 요청: 위스키 프로젝트에 ADB 기반 크롤링 계획 수립. 당시 범위는 계획뿐이며 기기 조작·수집·DB 적재는 시작하지 않았다.

목표: 앱에서 표시되는 상품·가격·조건을 근거와 함께 추출하고 기존 preview/검증/적재 경로로 연결한다.
대상 확정: 이마트, 코스트코, 이마트 트레이더스, 롯데마트. 롯데마트는 LOTTEON과 별도 판매처다. 미확정: 실제 기기, 매장/지역, 앱 화면별 가격 노출과 회원 가격 정책.
현황: Selenium 및 backend/crawler-playwright가 존재. 후자는 EMART/LOTTEON 수집, ingest-preview, safety-gates, ingest-write를 구현했다. 로컬 위스키 DB 연결은 복구했고 실제 목록 112개 조회를 확인했다. DB 쓰기/ADB 실행은 이번 계획 범위에 포함하지 않는다.

2026-10-15 최종 요청: 네 판매처 양주 수집 시나리오를 작성하고, 추후 쉘 스크립트/어드민 버튼 한 번으로 시작할 수 있도록 설계한다. 최신 실행 명세는 one-click-scenarios.md이며 이전 source-plan.md의 가정된 LOTTEON 대상보다 우선한다.

## 2026-10-15 반복 수집 구현 범위
사용자가 로그인과 실기기 검증을 완료하고 이마트/트레이더스 자동 반복 수집 구현을 요청했다. scripts/adb의 독립 Node.js CLI로 위스키 목록을 자동 전환/스크롤하여 검토 JSON을 저장한다. 별도 의존성 설치 없이 PowerShell/Bash에서 실행한다. DB 적재와 어드민 큐/버튼은 후속 범위다.

## 2026-10-15 추가 승인 및 범위 수정
사용자가 실제 가격 갱신, 미등록 상품 신규 등록, 이마트/트레이더스 전체 목록 수집과 상품 상세페이지 링크 수집을 요청했다. 앞선 계획의 DB 적재 제외는 더 이상 현재 범위를 나타내지 않는다. 43개는 화면 제한으로 얻은 표본이며 전체 목록으로 보고하지 않는다. 상품 식별은 이름 표기 차이와 용량/숙성/에디션/세트 차이를 구분한다. 상세 URL은 실제 공유 링크 등의 근거로 수집하며 추정 URL을 만들지 않는다. 상품 발견과 가격 검증을 분리하고 조건부 할인가를 일반가로 발행하지 않는다.
