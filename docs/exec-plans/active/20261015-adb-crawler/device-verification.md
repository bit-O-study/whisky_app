# 이마트/트레이더스 실기기 검증

2026-10-15 사용자 승인으로 ADB 화면 검증 시작. 사용자가 우선 범위를 이마트·트레이더스로 좁혔다. 롯데마트/코스트코는 후속으로 보류하며 설치 요청은 더 이상 선행 조건이 아니다.

## 확인한 내용

- 연결 기기: Galaxy S23(SM-S911N), 기본 사용자 0. 기기 식별값은 이 문서에 저장하지 않는다.
- 설치 앱: 이마트 `com.emart.today` 버전 5.2.9(versionCode 406), 이마트몰 `kr.co.emart.emartmall`. 기본 사용자 설치 목록에 롯데온/롯데마트GO/코스트코 없음.
- 전체 사용자 package 조회는 보조 사용자 권한 오류가 있어 `--user 0`으로 범위를 고정했다.
- 이마트 실행 화면: `com.emart.today/.presentation.activity.main.MainActivity`.
- 홈 안내 팝업의 닫기, 검색 진입, 와인그랩 메뉴를 확인했다. 홈에서 로그인하지 않은 상태였다.
- 일반 검색 화면에 기본 지점과 상품 가격이 보이지만, 아직 사용자가 선택한 기준 매장이 아니므로 운영 가격 근거로 사용하지 않는다.
- 사용자 안내에 따라 와인그랩을 우선 경로로 바꿨다. 와인그랩 진입은 로그인 화면으로 연결되며, 사용자가 직접 로그인하도록 요청했다. 비밀번호/OTP를 수집하거나 입력하지 않는다.
- 로그인 완료 후 와인그랩 위스키 목록에서 이마트/트레이더스 필터 및 상품명/용량/가격/최대할인가/카드할인 텍스트를 실기기 검증했다. 상세 지점/카드 조건은 미검증이다.

## 수집기 설계에 반영할 점

1. 주류 탐색은 홈 → 와인그랩 → 로그인/성인 확인 상태 검사 → 주류 카테고리/검색 조사 순서로 우선 검증한다. 와인그랩 채널의 상품 가격을 일반 매장 재고 가격과 혼용하지 않는다.
2. WebView UI hierarchy에 배경 화면/보이지 않는 노드가 함께 포함될 수 있다. XML의 모든 가격 문자열을 무조건 파싱하면 오수집한다. 현재 전면 화면과 양수 면적 bounds, 상품 컨테이너 문맥을 함께 확인해야 한다.
3. 화면 캡처와 XML은 서로 다른 순간에 확보되므로 전환 직후 불일치를 감지해야 한다. 예상 페이지 제목/상태가 안정된 뒤 캡처하고 상품명·가격을 대조한다.
4. UI dump는 매번 새 파일명으로 생성해 실패 시 이전 XML을 재사용하지 않는다. 출력 크기 제한도 명시한다.
5. 로그인 입력 중에는 자동 캡처/조작을 중단하고 사용자의 완료 통지 후 재개한다. 근거 파일은 로컬 임시 폴더에만 보관하고 Git에 추가하지 않는다.

현재 상태: 사용자 로그인 완료. scripts/adb/collect.mjs로 두 판매처 위스키 목록 자동 반복 수집 검증 완료(4화면씩, 총 11개). 앱 화면이 꺼지는 경우 깨우기, 스크롤 시 헤더와 하단 메뉴가 숨는 경우 TOP 이동을 반영했다.
