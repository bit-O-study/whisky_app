# 진행 상태

## 2026-10-15 자동 반복 수집 구현/실기기 검증

- 사용자 로그인 완료. 이마트 앱 5.2.9 / Galaxy S23에서 와인그랩 위스키 카테고리를 검증했다.
- `scripts/collect-winegrab.ps1` 및 `.sh` 한 번 실행으로 EMART → TRADERS 자동 전환, 겹치는 스크롤, 목록 추출, 중복 제거, 매 화면 체크포인트 저장을 구현했다.
- 실기기 4화면씩 연속 실행 성공: EMART 5개 + TRADERS 6개 = 11개. 재실행의 EMART 신규 추가 0개로 중복 제거를 확인했다. 결과는 무시되는 `artifacts/adb/smoke-20261015/products.json`에 있다.
- 화면당 약 7초. 자동 메뉴 탐색 시간은 별도다. 전체 목록 완주 시간/최종 개수는 아직 측정하지 않았다.
- 단위 테스트 9개 통과: 일반가/조건부 가격, 정상가/단위가격 분리, 배경 WebView, 잘린 가격/화면 밖 행, 판매처 배지 누락, XML 엔티티, 용량/키 분리, 불완전 XML, 스크롤 헤더.
- 실행 중 발견한 Android ResumedActivity 명칭 차이, 자동 화면 꺼짐, 스크롤로 숨는 헤더/하단 메뉴를 수정했다. 전면 앱 불일치/화면 상태 오류 시 결과 보존과 잠금 해제도 확인했다.
- 재개는 기존 결과 유지 후 처음부터 재순회한다. 같은 화면 3회 반복은 `stalled_or_end`이며 전체 수집 완료로 단정하지 않는다.
- 현재 수집 범위는 위스키 목록이다. 상세 지점/카드 조건/재고는 미확정이므로 전부 검토용으로 저장하며 DB 적재하지 않는다.
- 실행 설명: `scripts/adb/README.md`.

## 남은 후속 범위

위스키 외 카테고리, 상세 조건/점포 확인, DB 적재 계약, 어드민 버튼/작업 큐, 코스트코/롯데마트는 후속이다. 기존 네 판매처 전체 계획을 추적하기 위해 이 실행 계획은 active로 유지한다. 반복 수집 CLI 자체는 구현/실기기 표본 검증을 완료했다.

추가 검증: git diff --check 통과. 기존 Java 백엔드의 gradlew.bat test --offline은 Spring Boot 3.5.6 플러그인 캐시 부재로 실행 전 실패했다. 이번 변경은 Java/DB 코드와 독립된 Node.js 수집기이며 해당 9개 테스트와 실기기 연속 수집을 검증했다.
