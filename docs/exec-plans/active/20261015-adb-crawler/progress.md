2026-10-15: 저장소 계약·크롤러 구현·Android 공식 문서를 확인해 계획 초안을 작성했다. 첫 수집 앱과 순서는 사용자 답변 대기. UI 시안은 별도 이미지로 전달 완료. 이번 작업에서는 ADB 연결/기기 조작/크롤러 구현/DB 변경을 실행하지 않았다.
