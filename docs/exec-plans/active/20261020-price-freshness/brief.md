# Brief

## 문제
2026-10-20 운영 DB 점검에서 가격 157개 중 141개가 30일 넘게 갱신되지 않았다. 화면은 이를 알려 주지 않았다(목록 확인 시각에 연도가 없어 5개월 전 가격이 최근처럼 보임). 매장 전용 코스트코에도 "바로가기"가 붙었고, 휴대폰 첫 상품이 약 700px 아래에서 시작했다. 잘못된 구매 링크를 사용자가 알릴 방법도 없었다.

## 목표
- 목록·상세에 같은 규칙의 가격 신선도 표시(7일 이내 초록, 30일 이내 회색, 30일 초과 주황)와 연도 있는 확인 날짜.
- 링크 없는 판매처는 "매장에서 확인"/"링크 없음".
- 휴대폰 필터를 한 줄 선택 상자로, 소개 문구는 화면에서 감춤.
- 상세 "알려 주기" 신고(테이블 `liquor_report`가 생기면 자동으로 보임).
- 저장소 검사 규칙을 실제 날짜형 폴더와 맞춤.

## 비목표
- 최저가 계산에서 오래된 가격 제외(사용자 결정 대기, 표시만).
- 가격 수집 재개.

## 성공 기준
- 단위·E2E·lint·build·verify-repo 통과, 휴대폰 첫 상품 위치 약 360px.
