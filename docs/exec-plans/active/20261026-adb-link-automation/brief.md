# 등록 링크 가격 자동화

사용자 요청: 운영 서버 USB에 연결된 Android를 ADB로 검증하고 이미 등록된 링크로 가격을 자동 갱신한다. Change class: Crawler / Write Path. 기존 20261015-adb-crawler 및 20261023-data-pipeline-hardening 작업과 미커밋 변경을 보존한다. 이번 요청은 실제 서버 설치·수집·검증된 가격 반영·예약 실행을 포함한다.

범위는 이마트/트레이더스 공식 앱 링크다. 신규 상품 탐색, SSG/롯데온 등 별도 채널 확장, Java 변경은 포함하지 않는다. 상품/가격 검증이 불확실하면 스킵한다.
