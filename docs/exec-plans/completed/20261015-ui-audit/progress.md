# 검수 결과

2026-10-15. http://localhost:3001 개발 서버 실행. 1440×1000 데스크톱, 390×844 모바일 Edge 확인.
실제 DB 환경변수가 frontend에 없고 admin의 LIQUOR_SUPABASE_URL/LIQUOR_SUPABASE_SERVICE_ROLE_KEY도 없어 현재 실제 목록은 오류 상태다. 카드 검수에 한해 Playwright 브라우저 요청만 샘플 8개로 대체했다. 서버·DB·제품 코드는 변경하지 않았다. 실제 상품 상세/검색 결과 품질은 미검증.

## 우선순위

1. 높음: 모바일 정렬 버튼에서 기본/최신순/가격낮은순 등의 글자가 분리된다. nowrap과 가로 스크롤 또는 정렬 선택 메뉴로 수정.
2. 높음: CatalogPageClient의 정렬은 이미 로드된 liquors 배열 안에서만 이뤄진다. 전체 최저가 순으로 오해할 수 있으므로 서버 정렬 계약 적용 또는 현재 목록 내 정렬임을 표시.
3. 높음: 카드의 용량과 가격 갱신 시점을 비교 영역에 명시. 상세에는 갱신일이 있지만 목록 카드에는 없고 volume 필드도 카드에 표시하지 않는다.
4. 중간: 모바일 첫 화면을 광고·소개·여백이 대부분 차지한다. 배너 계약은 유지하면서 소개 높이/간격을 줄여 첫 상품을 더 빨리 노출.
5. 중간: 모바일 1열 + 4:5 이미지로 카드 하나가 약 600px를 차지한다. 작은 이미지의 가로형 또는 압축 카드로 비교 밀도 개선.
6. 중간: Lowest/vendors/BOTTLES/SORT 및 판매처 코드 EMART/LOTTEON을 한국어 표시명으로 통일하고 판매처 버튼의 터치 영역 확대.
7. 중간: 상품 신호는 46도 이상이면 Cask Strength, 15만원 이상이면 Rare로 추정한다. 근거 있는 속성만 표시하거나 도수/가격 등 실제 수치 라벨로 변경.
8. 중간: 오류 때 0 BOTTLES가 표시돼 상품이 없는 것으로 오해하기 쉽다. 조회 실패/결과 없음/로딩을 구별.
9. 낮음: 배너 선택 버튼은 실제 8×8px라 터치하기 어렵다. 시각적 점 크기는 유지하고 클릭 영역만 확대.
10. 낮음: 검색창은 placeholder만 있고 명시 label/aria-label이 없다. 접근 가능한 이름 추가.

모바일 가로 넘침은 현재 검수 범위에서 없었다. 구현 및 운영 반영은 수행하지 않았다.
