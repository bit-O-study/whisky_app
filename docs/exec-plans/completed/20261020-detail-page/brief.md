# Brief

## 문제
운영 사이트(앱도 같은 화면) 상품 상세 115개를 360px로 전수 점검한 결과, 판매처 가격이 두 줄로 쪼개지고 화면이 옆으로 밀리며(3개), 한글이 낱말 중간에서 끊기고, 빈 정보가 "WHISKY ·"(111개)·"UNKNOWN"·"0% ABV"·"—"로 노출됐다. 잘못된 주소는 "에러 코드: 알 수 없음" 화면이었다. 가격 추이는 113개에서 큰 빈 상자였고 영어 라벨·판매처 코드가 섞여 있었다.

## 목표
- 상세 화면이 휴대폰 폭에서 깨지지 않고, 비어 있는 정보는 숨기거나 안내 문구로 바꾼다.
- 라벨과 판매처 이름을 한글로 통일하고, 코스트코 최저가일 때 온라인 최저가 구매 버튼을 둔다.
- 30일 넘은 판매처 가격에 "오래된 가격" 표시를 붙인다(최저가 계산은 그대로).

## 비목표
- 1182~1184번 등 미입력 상품 데이터 보강(크롤러 작업).
- 목록 화면 재설계.

## 성공 기준
- 115개 상세 전수 점검에서 가로 넘침 0, "UNKNOWN"/영어 라벨 0, 빈 점 0.
- 숫자가 아니거나 없는 상품 주소는 "찾는 위스키가 없어요" 화면(noindex).
- `npm run test`, lint 통과.
