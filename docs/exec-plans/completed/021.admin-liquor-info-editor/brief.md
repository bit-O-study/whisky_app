# 021.admin-liquor-info-editor / brief

## 요청
- `/admin/manual-entry` 가격 입력 화면을 기준으로, 가격을 제외한 카탈로그 정보 수정 페이지를 추가한다.
- 우선 수정 대상은 화면에 보이는 상품 사진과 위스키 종류 정보이며, 같은 편집 흐름에서 이름/브랜드/국가/도수/용량도 함께 다룰 수 있게 한다.

## 가정
- 현재 로컬 저장소에는 배포된 `/admin/manual-entry` 소스가 없으므로, 기존 카탈로그 디자인 토큰과 라이브 페이지의 단순 관리자 폼 흐름을 기준으로 새 화면을 만든다.
- 카탈로그 노출 정보의 기준 테이블은 `public.liquor`다.
- 가격 데이터는 `public.liquor_price`에 있으므로 이번 변경에서 조회하거나 수정하지 않는다.

## 비목표
- 가격 입력/수정 기능 변경
- 인증 체계 추가
- Supabase 스키마 변경 또는 신규 의존성 추가
- 크롤러 적재 로직 변경

## 성공 기준
- 관리자가 주류를 검색해 선택하고, 가격 외 카탈로그 필드를 수정할 수 있다.
- API는 허용된 `liquor` 필드만 업데이트하고 가격 필드는 받지 않는다.
- 이미지 URL 수정 결과를 저장 전 미리 확인할 수 있다.
- 프론트 lint/build/test가 통과한다.

## 검증
- `npm run lint`
- `npm run build`
- `npm run test`
